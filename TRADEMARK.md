# REAN Trademark and Branding Policy

The REAN source code is open source under the Apache-2.0 license, and you are free to
use, modify, and self-host it under those terms. **However, the open-source code license
does not grant any rights to the REAN name, logo, or brand** (Apache-2.0 section 6
explicitly does not grant trademark rights).

## What this means

- **The code is free.** You may fork it, change it, and run your own version.
- **The name and logo are not.** "REAN", the REAN logo, and related branding are
  trademarks of the REAN project and its maintainers.

## Please do

- Use the code to build and run your own service under a **different name and logo**.
- State factually that your product is "based on REAN" or "powered by REAN", as long as
  you do not imply that the REAN project endorses, sponsors, or is affiliated with your
  version.

## Please do not

- Use the REAN name or logo as the name/branding of your own fork or service.
- Use the REAN name or logo in a way that suggests official status, endorsement, or
  affiliation without written permission.
- Register domain names, social accounts, or trademarks that could confuse users into
  thinking your version is the official REAN.

## Why

REAN is a community project funded by donations, grants, and training. Protecting the
name keeps the community safe from copycats and scams while leaving the code fully open
for anyone to reuse. This is the same approach used by many open-source projects (for
example Mozilla Firefox, WordPress, and the Linux kernel trademark).

## Questions or permission requests

If you would like permission to use the REAN name or logo, please open an issue or
contact the maintainers.
